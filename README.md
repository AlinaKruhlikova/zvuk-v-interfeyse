## 01 · «Лунный свет» (Клод Дебюсси)

- Музыка: Клод Дебюсси, «Лунный свет» (Suite bergamasque) — общественное достояние.
- Запись: исполнитель eldüendesüarez, Wikimedia Commons — https://commons.wikimedia.org/wiki/File:Debussy_-_Clair_de_lune.(Piano_Performance_by_eld%C3%BCendes%C3%BCarez).wav — лицензия CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). Изменения: запись сжата в MP3 и на сайте звучит фрагментами с плавными переходами. Файл `lunnyj-svet/zvuk/clair-de-lune.mp3` распространяется под той же лицензией CC BY-SA 4.0.
- Стихи: Поль Верлен, «Лунный свет» (1869) — общественное достояние. Перевод — Георгий Шенгели, приводится как цитата с указанием автора.
